# 生态修复成效复核

本项目面向生态修复年度复核，整理分期治理地块、实施措施、监测方法和区域环境背景。资料用于分析地块在不同治理阶段的观测变化及其适用范围。

## 资料

`data/manifest.json` 描述本地演练资料的字段。地块、监测、天气和项目复核分开记录，面积及时间字段使用各来源的业务含义，不代表真实行政统计。

字段含义及有效期约定见[资料口径](资料口径.md)。

## 成效复核与续建核定工具

`reviewtool/` 是每季复用的复核工具，按地块版本与实际暴露时段使用资料：

- 共同地面还原与面积去重（重合监测范围只计一次）；
- 分地貌分措施估计封育、封育加补植相对可比未治理地面的成效，
  直接实施与明确已受邻地影响的范围分开报告，同坡沟降雨过程不作独立证据重复；
- 测量切换凭同期重测桥接连接趋势，换算不确定度触及阈值时暂不判定；
- 合同验收按签订时的直接治理地面、观察窗和最低效果复核；
  已验收合同按 `evidence_cutoff` 还原当时数据版本与采用证据留快照，
  当前改判只作批注，不覆盖原签认；
- 续建按候选当前地貌与施工组合核定适用性，共用作业窗口与资金容量，
  已生效安排先行占用；证据仅见于合并治理范围的候选不能先作单项签认。

每季运行（`--as-of` 为复核截止日，默认当天）：

```sh
python3 -m reviewtool run --data data --out review_out --as-of 2026-11-24
```

输出 `review_out/report.md`（季报：成效复核、敏感性、验收、续建排布、
补报影响清单、不能签出事项）与 `review_out/report.json`（机器可读侧车，
供季度间比对与留痕）。续建适用阈值等判定参数见 `reviewtool/model.py` 的
`Config`，也可经 `--min-effect` 调整。

## 本地检查

使用 Python 3.11 或更新版本，无需安装第三方依赖。

```sh
python3 -m unittest discover -s tests -v
python3 -m compileall -q reviewtool tests
```
